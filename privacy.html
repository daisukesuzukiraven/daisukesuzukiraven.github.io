プライバシーポリシー

quote（以下「本アプリ」）は、チームのメンバーが心に残った言葉を記録し、ふり返り、実践を重ねるためのツールです。本アプリが扱う情報と使い道は次のとおりです。

1. 扱う情報

  • メールアドレス・表示名・パスワード（パスワードは復元できない形で保存します）
  • 登録した言葉・出典・感情や考え・行動計画・実践記録、言葉を開いた日時と回数
  • 毎朝の通知の設定と送信の記録
  • ログイン・招待などの操作の記録（日時・接続元の IP アドレス）

2. 使い道

  • ログインと、本人の言葉・記録の表示
  • 招待・パスワード再設定・毎朝の言葉のメールの送信
  • 不正なログインの防止と、障害の調査

これ以外の目的には使わず、広告や第三者への提供は行いません。

3. Google のサービスの利用

本アプリは、メールの送信のためだけに、送信専用の Gmail アカウントで Gmail API の「メールの送信」権限を使います。利用者の Gmail の受信トレイやメールの内容を読み取ることはありません。Google API から受け取った情報の取り扱いは、Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含む）に従います。

4. 保存場所と保存期間

情報は、本アプリの運営に使うクラウドサービス（Render・Neon）に暗号化された通信で保存します。毎日のバックアップは暗号化して7日間保存します。操作の記録と通知の送信記録は1年で削除します。

5. 削除の依頼

退会してすべての情報を削除したい場合は、チームの管理者に依頼してください。管理者が利用者と、その言葉・実践記録などをすべて削除します（操作の記録は、誰の操作かが分からない形で残ります）。

6. お問い合わせ

本アプリと本ポリシーについてのお問い合わせは、チームの管理者までご連絡ください。
